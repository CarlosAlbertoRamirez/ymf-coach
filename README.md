# YMF Coach (proyecto académico)

Sitio estático (HTML, CSS y JS). Para publicarlo en GitHub Pages:

1. Crea un repositorio público nuevo llamado `ymf-coach` (no uses `ymf-web`, es otro proyecto).
2. Sube el contenido de esta carpeta a la raíz del repositorio (index.html, styles.css, script.js y la carpeta assets).
3. En el repositorio: Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / carpeta `/ (root)` > Save.
4. En 1 o 2 minutos quedará en: https://TU-USUARIO.github.io/ymf-coach/
